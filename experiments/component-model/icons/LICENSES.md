# Spike icon drafts

These are original SVG drawings made for this repository on 2026-11-05; no stock PNG, vendor logo, external artwork or generated raster image was used. Source is the SVG itself. They use the repository's Apache-2.0 licence.

| File | Role | Source | Licence |

| served-model.svg | Available model | Original repository drawing | Apache-2.0 |

All use a 40 × 40 viewBox, 2-unit outline stroke, jungle green `#30BA78`, and a light-green `#E4F5EB` tile. These are review drafts, not a claim of SUSE brand approval. Before adopting the full family, ask SUSE brand/design for an existing library and its licence. No external message was sent during this spike.

The existing stock PNG assets and ComponentType `iconbase64` fields are untouched by this experiment. This file covers only these three drafts; inventory and licensing of the remaining legacy assets belongs to the full redesign.
